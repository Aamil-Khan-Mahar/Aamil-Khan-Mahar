## What I'm working on

- **At Afiniti:** I train and maintain production models (tree-based, Stan-based Bayesian and regression-tree ensembles) that route calls for a contact-center client, from SQL ETL and feature engineering to simulator validation.
- **Agentic AI:** a LangGraph, tool-calling agent on AWS Bedrock that automates model-underperformance analysis across my team.
- **[Masters-App](https://github.com/Aamil-Khan-Mahar/Masters-App):** a local app that runs a whole grad-school application cycle with a team of Claude agents. It covers program discovery and research, fit scoring, an entry-requirements checker, a statement coach and a tailored resume per program. FastAPI, React, TypeScript.
